# eva1-taller-de-bicicletas
# Landing page para un taller de bicicletas

    Pagina web en desarrollo donde se exponen diferentes servicios tecnicos para bicicletas, y venta de algunos repuestos o accesorios, exhibiendo detalles simples, precios, y un boton de acción con el texto "encargar" que se agregará una función a futuro, posiblemente un carro de compras.

    La problemática abordada con la pagina web, es apoyar a un taller de bicicletas local a publicar los servicios que presta y la venta de algunos accesorios para usuarios de bicicletas de la zona. De esta manera se pretende dar mas seriedad y comodidad  a los usuarios y usuarias de bicicletas del sector.

    Para el proyecto se utilizará "visual studio code" y para programar la pagina web se utiliza lenguaje de programacion HTML con apoyo de algunos estilos CSS para dar un aspecto mas amigable al usuario.

    En algunas secciones se utiliza ia copilot para
    modificar algunos aspectos visuales y funcionales de la web, comentados debidamente donde hubo intervención de IA copilot.

    **Importante agregar que la web está en desarrollo, y la seccion formulario de contacto aun no cuenta con funcionalidades, es solo visual.**
